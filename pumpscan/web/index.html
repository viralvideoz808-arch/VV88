Consensus rules

A signal fires only when the BUY votes reach the threshold, no agent votes AVOID, and none of the 8 safety agents (veto) objects. 25/25 means unanimous: every agent must have data and agree. After the window closes the dashboard records what the price actually did, so the track record above is measured, not claimed. Signals and rules are saved in this browser only.

Signals are probabilistic calls from heuristics, not guarantees or financial advice. Most pump.fun coins go to zero, and safety checks cannot catch every rug. Only trade money you can afford to lose entirely, size small, and use the stop.
